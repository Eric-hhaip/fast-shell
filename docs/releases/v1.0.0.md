## 本次包含

### 连接管理
- 连接增删改、分类管理（可新增 / 删除分类）、分组折叠、关键字搜索、右键菜单
- 密码 / 私钥两种认证，支持私钥密码短语
- 主机指纹校验：首次连接核对 SHA256 指纹，指纹变化时红色告警
- 快速连接：`user@host:port` 直接开临时会话

### 终端
- 多标签并行会话，256 色 / 真彩色，10000 行回滚缓冲，窗口尺寸自适应
- 功能键条、断线一键重连、字号实时调整
- 日志不截断：字符网格渲染，任意长度输出都不掉帧

### 服务器监控（`⌘⇧M`）
- 主机概览、CPU / 内存 / Swap / 磁盘 / 网络实时曲线、CPU 占用 Top 进程
- Docker 容器管理：列表与用量、启动 / 停止 / 重启 / 删除、容器日志全屏查看

### SFTP 文件传输（`⌘⇧F`）
- 目录树、文件在线查看与编辑、拖拽上传、下载到 `~/Downloads` 或自选位置
- 传输队列：进度、实时速度、并行 2 任务、可取消；失败原因保留展示

### 安全
- 连接信息（含密码、私钥）AES-256-GCM 加密落盘
- 密钥由「主密钥文件（0600）+ 本机硬件 UUID」经 HKDF 派生 —— 配置拷到别的电脑无法解密
- 纯本地，无遥测、无账号体系

## 系统要求

- macOS 12+（Apple Silicon / Intel）
